# 灵蛇智采网页原型

这是一个不依赖框架和后端的静态交互原型，用于预览登录、项目进展、上位机追踪和 GitLab 开发入口。

## 本地预览

在仓库根目录执行：

```bash
python3 -m http.server 8080 --directory web-demo
```

然后访问 <http://localhost:8080>，填写真实姓名、设置至少 6 位密码并选择项目职责，即可直接进入工作台。

职责包括控制与路径规划、SLAM、系统架构设计、指导老师、负责人，也可以选择“其他”并自行填写。

## 配置 GitLab 地址

修改 `app.js` 第一行附近的 `GITLAB_PROJECT_URL`。

> 注意：当前登录和机器人遥测仍为界面演示。密码只在浏览器中进行格式校验，不会保存或发送。正式上线前需要增加后端、数据库、权限校验，并将上位机数据接入 WebSocket 或 MQTT。
